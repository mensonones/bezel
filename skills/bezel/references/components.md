# Mobile Component Cookbook & 7-State Matrix

When building or refining a single mobile component rather than an entire screen, Bezel enforces a strict component-level discipline.

---

## The 7-State Mobile Matrix

Every interactive component generated by Bezel must account for and implement **all 7 mobile states**:

| State | Visual Treatment | Touch & Feedback |
|---|---|---|
| **1. Default (Idle)** | Resting appearance, locked token colors, crisp hairline or elevation. | Ready for touch, full opacity. |
| **2. Pressed (Active)** | Instant spring scale-down (`scale: 0.96`), surface tone darkens/lightens by 5–8%. | Immediate `onPressIn` light haptic pulse. |
| **3. Focused** | Subtle high-contrast outline (`2pt` accent glow) or border tone change. | For text inputs or hardware accessibility navigation. |
| **4. Disabled** | Reduced opacity (`0.4`), neutral grayscale tone, pointer events disabled. | No haptics, touches ignored cleanly. |
| **5. Loading / Skeleton** | Inline shimmer wave or subtle activity indicator replacing or adjacent to label. | Interactive touches locked to prevent double submission. |
| **6. Error** | Border turns to error token (`#FF3B30`), micro-shake animation, helper copy. | `NotificationError` or heavy double haptic buzz. |
| **7. Success** | Smooth morph or checkmark icon badge, green accent token. | `NotificationSuccess` gentle haptic confirmation. |

## 10 Named Component Archetypes

### C01 · Tactile Haptic Pressable
- **Purpose:** Universal base wrapper for buttons, cards, and list rows.
- **Specs:**
  - Uses `react-native-reanimated` with `useAnimatedStyle` or Compose `animateFloatAsState`.
  - Spring config: `{ damping: 15, stiffness: 300, mass: 0.8 }`.
  - `onPressIn`: Trigger `Haptics.impactAsync(Light)` and animate `scale.value = 0.96`.
  - `onPressOut`: Animate `scale.value = 1.0` with spring bounce.
  - Accessible hit slop: minimum `44 × 44pt` bounding box.

### C02 · Snap-Detent Bottom Sheet
- **Purpose:** Contextual inspection, filters, secondary actions without losing screen context.
- **Specs:**
  - Rounded top corners (`16pt` to `24pt` radius).
  - Grab handle pill (`36 × 5pt`, `#8E8E93` with 40% opacity).
  - Pan gesture responder tracking finger `translationY` and `velocityY`.
  - Velocity threshold: Swiping down faster than `500pt/s` snaps to dismiss.
  - Background overlay: Animated semi-transparent backdrop (`rgba(0,0,0,0.4)`).

### C03 · Large Title Nav Header
- **Purpose:** Flagship screen navigation with dynamic scroll collapse.
- **Specs:**
  - Expanded: `34pt` Bold title with `16pt` horizontal padding.
  - Collapsed: `17pt` SemiBold centered title with hairlineWidth bottom border (`0.5pt`).
  - Interpolation: Driven by scroll container's `contentOffsetY` between `0` and `80pt`.
  - Right accessory: Compact icon button or text action ("Done", "Edit").

### C04 · Inset Grouped List Row
- **Purpose:** Settings, profile data, options, and structured item lists.
- **Specs:**
  - Height: `48pt` (single line) or `64pt` (two lines with subtitle).
  - Leading accessory: Optional rounded square icon badge (`28 × 28pt`, `6pt` radius).
  - Title: `17pt` Regular. Subtitle: `13pt` Regular muted.
  - Trailing accessory: Value text (`15pt` muted) + optional chevron icon (`#C7C7CC`).
  - Separator: `0.5pt` hairline divider indented past the leading icon (`insetLeft: 56pt`), hiding separator on the last row of the group.

### C05 · Floating Action Capsule / Pill
- **Purpose:** One-handed thumb commands, playback bars, quick actions.
- **Specs:**
  - Geometry: `48pt` to `56pt` height, pill radius (`height / 2`).
  - Material: System blur material (`UIBlurEffectStyleSystemUltraThinMaterial` or dark acrylic).
  - Subtle hairline border: `1pt` border with `10%` white or `8%` black.
  - Elevation: Soft physical shadow (`shadowOpacity: 0.15`, `shadowRadius: 16`, `shadowOffset: { width: 0, height: 6 }`).

### C06 · Keyboard-Docked Action Tray
- **Purpose:** Primary form submission buttons that never get buried under the keyboard.
- **Specs:**
  - Glued to the top edge of the software keyboard.
  - Animates vertically in exact sync with keyboard show/hide events (duration ~250ms).
  - Safe area clearance when keyboard is hidden (`paddingBottom: insets.bottom + 12`).
  - Flush padding when keyboard is visible (`paddingBottom: 8`).

### C07 · Segmented Pill Switcher
- **Purpose:** Tab switching, view mode toggling, frequency selection.
- **Specs:**
  - Background track: Rounded pill track with subtle inset background (`#767680` with 12% opacity).
  - Active thumb: Elevated white (light mode) or surface-dark pill with micro-shadow.
  - Sliding animation: Spring-driven transition of thumb position matching selected index width and offset.
  - Haptic: Immediate `selectionAsync` on tab touch.

### C08 · Swipeable Action Row
- **Purpose:** Quick archive, pin, delete, or mute in feeds and inboxes.
- **Specs:**
  - Underlying action shelf: Revealed behind row during horizontal pan.
  - Spring detent threshold: Swiping past `80pt` reveals action buttons; swiping past `60%` screen width triggers full-swipe action with haptic confirmation.
  - Haptic trigger: Crossing the threshold fires a crisp `impactAsync(Medium)`.

### C09 · Shimmer Skeleton Placeholder
- **Purpose:** Structural loading states that prevent visual pop and layout shift.
- **Specs:**
  - Shapes: Rounded rectangles (`4pt` radius for text, `8pt` for cards, `50%` for avatars).
  - Base tone: `rgba(150, 150, 150, 0.12)`.
  - Shimmer highlight: Continuous linear gradient or animated opacity sweep (`0.3` to `0.7` to `0.3`) over `1200ms`.
  - Zero layout shift: Skeleton dimensions match the exact line heights and padding of real content.

### C10 · Contextual Bottom Action Sheet
- **Purpose:** Multi-action menus, sharing options, destructive confirmation sheets.
- **Specs:**
  - Inset modal container resting above bottom safe area.
  - Action items separated by hairline dividers.
  - Destructive options highlighted in system red (`#FF3B30`).
  - Prominent separate "Cancel" button isolated at the bottom for effortless thumb reach.
